
# 🍕 Domino's Pizza Sales Performance Dashboard

An end-to-end data analysis project showcasing sales performance metrics, key performance indicators (KPIs), and actionable business insights for Domino's Pizza. This repository contains the raw data, SQL database setup, analytical scripts, an interactive Excel dashboard, a project documentation report, and visual previews.

## 🚀 Key Features & Objectives
* **Sales Trends & Analysis:** Analyzed peak ordering hours, popular pizza categories, and top-selling items to understand customer purchasing behavior.
* **Interactive Dashboard:** Built dynamic pivot charts in Excel to track total revenue, total orders, average order value, and item-wise sales performance.
* **SQL Queries:** Implemented backend queries to extract insights and cross-verify aggregate metrics.
* **Business Recommendations:** Outlined operational strategies in the project documentation to improve peak-hour staffing and inventory management.
